# Первичная проверка среды GASS Configurator

**Вход.** Корень с `Configurator.slnx`, запрос первичной настройки и доступные Windows-среды. Используй этот Skill при настройке новой рабочей папки или при проверке её готовности.

**Границы работы.** Работай только с открытым репозиторием. Не меняй соседние проекты, глобальные настройки, API-ключи или прикладной код. Зависимости, CI, сторонние агенты, плагины, сервисы и платные интеграции требуют отдельного запроса. Не удаляй данные и не выводи секреты. Опасные или необратимые команды исключены из обычной настройки и допустимы только по прямому поручению.

**Исследование.** Начни со структуры и конфигурации. Затем адресно изучи все ключевые для архитектуры и качества модули. Исключи бинарники, зависимости и генерируемые файлы. Не читай все исходники подряд.

**Проверки.** Дорогие, сетевые или потенциально изменяющие данные операции предварительно согласуй. Полный прогон требует обоснования. Для непроверенной операции укажи фактический статус.

1. Открой [README](../../../README.md), [инструкции проекта](../../../AGENTS.md) и [карту](../../../docs/architecture.md). Сверь фактические SDK, Windows Desktop Runtime, [проект приложения](../../../Configurator.csproj) и [CI](../../../.github/workflows/ci.yml).
2. Определи доступные команды сборки и [тестового скрипта](../../../Run-Configurator-Tests.ps1). Подтверди адресный запуск, если это самый дешёвый способ проверить среду. Полный прогон выбирай для общей базовой проверки, если она запрошена или подтверждённо нужна. Отметь доступные build-анализаторы и отдельные команды линтинга или форматирования, если они существуют.
3. Раздели доступность от прохождения. Для Manual отметь возможность запуска WPF. Для Integration проверь наличие выделенного SQL Server или LocalDB без чтения паролей или записи в рабочую БД. Для Offline укажи тесты изоляции SQL, пакетов и восстановления.
4. При обнаружении расхождения внеси точечное уточнение `AGENTS.md` в рамках порученной настройки. Опирайся на подтверждённые сведения, сохраняй полезные правила и избегай дублирования Global AGENTS.

**Готово.** Есть список команд с рабочим каталогом, фактическими статусами и доказательствами, пробелы WPF/SQL, перечень правок и приоритетный следующий шаг.
