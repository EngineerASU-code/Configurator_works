Прогон завершён по прямому указанию пользователя «Заверши с текущими результатами». Полная работоспособность режима 3 не подтверждена: воспроизведены дефекты фильтров, создания PLC, отображения справочников, Matrix и журнала. Код приложения не изменялся, сборка и автоматические тесты в этом прогоне не запускались.
