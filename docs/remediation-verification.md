## Границы допуска

Проверки конкурентного удаления опираются на состав записи и её зависимости в момент транзакции. После удаления и повторной вставки полностью идентичной строки без версии или неизменяемого идентификатора схема не позволяет различить два экземпляра. Сторонний SQL-клиент может создать логическую ссылку после завершения транзакции. Compare повторно читает источник перед записью и атомарно изменяет назначение. Общей транзакции между файлом и SQL Server нет.

Для тестовой эксплуатации доступны основные операции с существующей структурой. Допуск к работе с аппаратными адресами и к массовым исправлениям данных зависит от предметного решения по R9. Ручная матрица всех ролей и кнопок остаётся открытой.
