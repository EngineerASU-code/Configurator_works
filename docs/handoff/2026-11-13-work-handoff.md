## Что изменено сегодня

- Исправлена работа фильтра и пагинации таблиц: фильтр не применяется к отсутствующему столбцу, состояние кнопки зависит от текущей таблицы, обновление страницы не должно перезаписывать более свежий результат.
- При изменении первичного ключа запись сохраняется по исходной идентичности строки; конфликт нового значения обрабатывает ограничение базы данных.

- Для `Area` используется `AreaName` как ключ справочника и понятное имя как подпись; `AreaName` в форме добавления — обычный вводимый текст.
- В «Объектах проекта» PLC и Area показывают свои поля. Выбор класса загружает карточку без мигающего старого превью; отложенный ответ предыдущего выбора не должен подменять новый.

Затронуты окна добавления/редактирования, `MainWindow`, `Modes/ProjectModeView`, `Services`, `ViewModels`. Удалён дублировавший стартовую логику `Modes/ProjectModeView.StartupFixes.cs`.

## Проект и команды

- Стек: C# / .NET 8 (`net8.0-windows`) / WPF; SQL Server через `Microsoft.Data.SqlClient`, ScriptDom и Newtonsoft.Json.
- CI находится в `.github/workflows/ci.yml`. Сборка и тесты CI выполняются отдельно и не подтверждены локальной Release-сборкой.
- Из корня репозитория восстановить зависимости при необходимости: `dotnet restore Configurator.slnx` (может требовать сеть).
- Сборка: `dotnet build Configurator.csproj -c Release --no-restore`.
- Тесты безопасности: `dotnet test tests\Configurator.Security.Tests\Configurator.Security.Tests.csproj -c Release --no-restore --logger 'console;verbosity=minimal' -v quiet`.
- Перед тестами изолировать TEMP/TMP в отдельном PowerShell процессе: `$testTemp = Join-Path (Get-Location) ('artifacts\quality-temp-' + [guid]::NewGuid().ToString('N')); New-Item -ItemType Directory -Path $testTemp -Force | Out-Null; $env:TEMP = $testTemp; $env:TMP = $testTemp`. Один adversarial-тест удаляет фиксированный `outside.txt` внутри TEMP.
- На рабочем компьютере 13.11.2026 был .NET SDK `10.0.401`; `global.json` в проекте нет. Для сборки требуется SDK с поддержкой .NET 8.
- Отдельные линтер и форматтер не настроены; используются компилятор и штатные анализаторы SDK.
- `Core/` — архитектура и контракты; `Application/` — сервисы приложения; `Infrastructure/` — SQL и хранилища; `Services/` — прикладные службы; `MainWindow/`, `FirstScreen/`, `Modes/`, `Themes/`, `ViewModels/` — WPF интерфейс.
- Offline-режим не должен обращаться к SQL Server. Соединения проходят через `SqlProviderGuard`; открытие `.cfgproj` не подключает базу. Для архивов проекта важно сохранять восстановление после сбоев и ограничения ZIP-пакета.
