# Compare, Matrix и Program — передача на ручную проверку

## Compare

- Точка входа: `Modes/CompareWindow.xaml.cs`, `RunTransferAsync`. Выбрать две тестовые копии одного проекта, сравнить, перенести поле и затем объект в обоих направлениях. Проверить оба источника после переоткрытия. Успех автоматически запускает новое сравнение.
- Точки останова: `Core/Compare/CompareTransferPreview.cs`, `Evaluate` — причина недоступности, целевой ключ и набор полей. `Services/DatabaseService.Rows.cs`, `UpdateCompareRowAsync` — проверка исходной версии, связей и SQL-прав, один UPDATE для объекта. Для SQL использовать выделенный LocalDB.
- Если перенос недоступен, проверить подсказку стрелки, происхождение пакетов, права и наличие открытого редактора у целевого файла. На стороне SQL отдельно проверить активные триггеры и физические связи.

## Matrix

- Точки останова: `Modes/ProjectModeView.ProgramTools.cs`, `ShowSelectedMatrix` — выбранная строка и ключ PLC / класс / Record. `Modes/MatrixCatalogControl.xaml.cs`, `LoadSelectedAsync` — выбор дочернего набора данных.
- На копии открыть Blending Tanks и ещё одну матрицу. Проверить Commands, карту команд, Device List (позиции и варианты), Devices (подбор объектов). Проверить отмену переключения при незаконченной правке, сохранение и повторное открытие.
- AWL: в текущем коде есть экспорт Matrix. Контракт импорта для Program и Matrix остаётся открытым. Перед реализацией собрать входные примеры для обоих форматов и определить обязательные поля, сопоставление ключей, предпросмотр и атомарное применение.

## Program

- Карточка сохраняет активный раздел. Для полей Sequence остаётся отдельная кнопка «Сохранить последовательность», для условий — «Сохранить переход». Точки останова: `Modes/ProgramManagementControl.xaml.cs`, `SaveProgramCardAsync`, `SaveEntityAsync`, `LoadSequenceChildrenAsync`.
- В матрице условий Dest выбирается из вхождений текущей последовательности. Для ручной проверки изменить назначение и бит, сохранить и повторно открыть тот же проект.
- Перемещение Online выполнено одной SQL-транзакцией. Точка останова: `Services/ProgramRepository/ProgramManagementRepository.Move.cs`, `MoveOnlineStepAsync`. При неподтверждённых ключах, неизвестной таблице со ссылками, активном UPDATE-триггере или задействованном внешнем ключе операция блокируется. Проверить сценарий на копии реальной схемы и вручную проверить относительные Prev/Next.
- Queues: элемент создаётся после выбора очереди из той же программы. Проверка родителя повторяется при записи. Дальше добавить связанные справочники статусов, матриц, вариантов устройств и рецептов по контексту последовательности. Точка останова: `Services/ProgramSupportRepository.cs`, `SaveAsync`, секция `queue-selections`.
- Messages: проверить CRUD и запись разных типов на копии реальной схемы. Сверить значения с `Prog_MsgTypes`. Точка останова: `ProgramSupportRepository.LoadAsync`, проверка уникального ключа.
